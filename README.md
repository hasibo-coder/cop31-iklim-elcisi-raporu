# Bir İklim Elçisinin Gözünden COP31

COP31 Antalya'da katıldığım 33 oturumun bir araya getirilmiş nihai raporunun web sitesi.

Yazar: Hasan İbrahim Bulduk, İTÜ İklim Elçisi.

Site statik HTML, CSS ve JavaScript'ten oluşur; `index.html` ana sayfadır. Arka plan videoları Pexels'ten alınmıştır, kaynaklar Hakkında sayfasında listelenir. Yazı tipleri: Newsreader ve Public Sans (SIL Open Font License).

## English version
The English version of the site lives under `en/` and mirrors the Turkish pages one to one. Every page has a TR | EN switch in the top menu; the site opens in Turkish by default. Shared assets (CSS, fonts, videos, scripts) stay in the root; the scripts pick their language from `<html lang>`.
