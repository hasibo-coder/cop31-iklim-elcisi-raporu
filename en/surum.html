Versions and corrections

The report welcomes constructive criticism. If you spot a wrong figure or statement, write to me; I publish verified corrections on this page with their date.

How to report a correction

Send an email: bulduk23@itu.edu.tr. Put "COP31 report correction" in the subject line. It helps if your message includes:

  1. Where? The page or section name (for example "Theme 3, figure cards").
  2. What does it say? The statement or figure you want corrected.
  3. What should it say? With its source (link, report name, date).

If a figure label changes (for example Speaker-reported → Verified), the Figures and Verification page is updated too.
